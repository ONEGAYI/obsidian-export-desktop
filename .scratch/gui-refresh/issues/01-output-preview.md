# 统一输出路径预览与导出确认

发布快照：[GitHub #38](https://github.com/ONEGAYI/obsidian-export-desktop/issues/38)。后续以 Issue 正文与状态为准。

Parent spec: #37
Blocked by: 无
状态：ready-for-agent。此任务只覆盖一条完整用户路径：修改来源/目标/保留根文件夹 → 查看准确落点 → 确认导出。

## 问题与交付

当前确认框直接拼接路径，后端只对目录来源追加根文件夹名；单文件、盘符根和相对路径可能预览不一致。交付贯穿桌面 Rust、Tauri 调用、首页、确认框与测试的可靠预览，不先拆出单独“后端 ticket”。

## 实现范围

- 新增只读 `preview_export_destination` 命令，复用 `resolve_destination` 及启动时的绝对路径解析；返回解析目标、来源类型或错误。
- TS 提供类型化封装，首页增加根文件夹选项与输出路径展示。此票可以沿用原视觉外壳，最终样式由后续票完成。
- 首页和确认框共用同一预览状态；根文件夹主要编辑入口在首页，确认框显示只读选择与路径。
- 空输入不请求，输入变更清掉旧结果；请求合并约 150ms，乱序结果仅接受最新输入。保留既有 localStorage 键与偏好。
- 预览无副作用：不创建目录、不扫描 vault、不启动边车、不占用进程槽。预览不替代真正导出的有效性检查。
- 继续支持手动单文件路径；浏览按钮仍选目录。不扩展 CLI 或文件系统插件权限。
- 执行后链接检查仍使用 `start_export` 返回的实际落点。

## 验收清单

- [ ] 真实临时目录下，开/关保留根文件夹的预览与启动公共解析一致。
- [ ] 单篇笔记及无末级名称的根路径不追加来源名；中文空格、尾部分隔符和相对路径有覆盖。
- [ ] 预览命令不会创建任何输出目录；无效/不可访问来源不伪装成有效文件。
