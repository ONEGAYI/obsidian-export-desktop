## 用户可见交付

- 纸白淡紫主题与对应深色主题；来源、目标名称与可编辑路径；独立输出区和底部导出操作栏。
- 宽高独立响应：CSS 视口宽度 <1000px 隐藏配置详情，>=1000px 显示右栏；高度 <640px 使用单行胶囊，>=640px 使用展开输出区。
- 默认 760×520；最小 560×480，保持现有窗口配置。正常默认首页一屏可见，宽屏主区随窗口伸展。
- 胶囊一行包含根文件夹复选框与输出路径；完整路径支持悬停、键盘聚焦查看与选择复制。
- 详情读取真实 ExportOptions，含转换、渲染、链接检查及其他非默认项。图像里的示例值不作为默认值。
- 用户点击导出仍先确认；转换选项入口在全部宽度都可用。

## 验收清单

- [ ] 760×520 仅有路径、输出胶囊与底部操作；无“导出流程”、步骤条、下方折叠配置摘要。
- [ ] 999×800：无详情、输出展开；1000×520：有详情、仍为胶囊。
- [ ] 1000×639 与 1000×640 分别为胶囊/展开，宽高断点互不替代。
- [ ] 560×480 的英文标签与 300 字符路径不会撑宽页面；胶囊不换行，底部按钮可达。
- [ ] 空输入没有虚构名称；尾部分隔符、盘符根有合理显示；实际提交路径不被省略文本替代。
- [ ] 图表关闭显示未启用；检查关闭显示不适用；frontmatter 三态与递归嵌入文案准确。
- [ ] 设置后返回首页，详情同步当前值；窄宽切换不重置输入、根选项或预览状态。
- [ ] 长路径键盘可读可复制；隐藏详情没有不可见焦点；来源/目标输入的浏览和粘贴功能保留。
- [ ] 760×520 与 1440×900 覆盖中文/英文 × 浅色/深色，另测 system 跟随；125%/150% 缩放有记录。
- [ ] 真实浏览器/WebView 可见性、边界与截图验证，不能只断言一个布尔断点函数。
- [ ] `pnpm -C desktop test`、`pnpm -C desktop build` 通过；若触及 Rust，追加对应桌面测试。
- [ ] 设置页使用的 PathPicker 不因首页变体而退化，localStorage 键和默认选项无变化。
